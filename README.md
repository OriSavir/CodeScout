# CodeScout

🚀 **CodeScout** is a command-line tool that leverages LLMs to review code within a local developer environment. It helps analyze code, provide style suggestions, and detect potential issues.

## Features (Planned)
- 🔍 AI-powered **code review** for best practices & bug detection
- 🎨 **Style & linting** suggestions for cleaner code
- 🤝 **Personalization** ability to integrate within your own LLM environment or connect API keys to common cloud-hosted models
- 📂 **Multi-language support** for flexible usage
- ⚙️ **Custom rules & configurations** to fit your workflow
- 🏎️ **Fast & lightweight CLI** for easy integration
